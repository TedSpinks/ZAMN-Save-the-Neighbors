# Inputs

Patches that `build.py` starts from. They are not built from source in this repository.

| File | What it is |
|---|---|
| `controls/ZAMN_ReverseFire.ips`, `controls/ZAMN_Strafe.ips` | The Reverse Fire and Strafe patches (the Reverse Fire and Strafe releases are these plus the checksum and legacy-site handling) |
| `controls/combo_rf_hitbox_ri_blood.ips` | Reverse Fire + Hitbox 150 + Reverse Inventory Cycling + Bloody Disgusting Edition, the base of Save the Neighbors |
| `third_party/zamn_pause_2mb.ips` | The pause loop and 2 MB expansion from ZAMN: Splitscreen + Quality of Life (AuroraBorealis) |
| `third_party/reverse_inventory_cycling_v1.1.ips` | Reverse Inventory Cycling v1.1 (Stanley_Decker, Sloat) |
| `third_party/bloody_disgusting_edition.ips` | Bloody Disgusting Edition (Board_Avenger) |

The third-party files are other authors' work, kept here unmodified and credited in the [README credits](../README.md#credits). All are applied to a clean *Zombies Ate My Neighbors (USA)* ROM (CRC32 `7CFC0C7C`).
