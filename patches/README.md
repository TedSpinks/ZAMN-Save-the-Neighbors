# Patches

One folder per release. Each has a `README.md` (what it does, how to patch, which other patches it was tested with and how to apply the combination) and a `TECHNICAL.md` (design, testing, problems found).

| Folder | Patch |
|---|---|
| [reverse-fire-strafe](reverse-fire-strafe/README.md) | `zamn-reverse-fire.ips`, `zamn-strafe.ips` |
| [pause-map](pause-map/README.md) | `zamn-pause-map.ips` |
| [drop-in](drop-in/README.md) | `zamn-drop-in.ips` |
| [save-the-neighbors](save-the-neighbors/README.md) | `zamn-save-the-neighbors.ips` |

The IPS files themselves are attached to GitHub releases, not stored in the repository.
